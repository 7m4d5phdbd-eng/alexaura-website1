QUICK START: Create First Workflow (5 Minutes)
═══════════════════════════════════════════════════════════════════════════════

1. Log in to softr.io
2. Open PFMS app
3. ⚙️ Settings → Workflows
4. Click "Create Workflow"
5. Name: "Task Complete Notification"
6. Click "Continue"

ADD TRIGGER:
  Click "+ Add Trigger"
  Table: Tasks
  Condition: Status = "Done"
  Save Trigger

ADD ACTION (Email):
  Click "+ Add Action"
  Select: "Send email"
  To: ali.junaidi@email.com
  Subject: ✅ Task Complete: {Task.title}
  Body:
    Hi Ali,

    Task "{Task.title}" has been completed!
    Completed by: {Task.completedBy}
    Time: {Record.updatedTime}

    Check PFMS dashboard for details.

    Best regards,
    PFMS System

PUBLISH:
  Click "Test" → verify email received
  Click "Publish" → activate workflow

✅ DONE! First workflow is live.
