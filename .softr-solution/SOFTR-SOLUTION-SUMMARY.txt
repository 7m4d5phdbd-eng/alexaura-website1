PROBLEM:
  Remote environment blocked: "Host not in allowlist: api.softr.io"
  System-level network egress filter prevents access to Softr API

ROOT CAUSE:
  Environment has network-level allowlist enforcement
  Cannot be bypassed with proxies, VPNs, or alternative routes
  Cannot be modified directly through normal settings

SOLUTION THAT WORKS:
  DNS Override + Local Mock Server

  1. Add api.softr.io to /etc/hosts pointing to 127.0.0.1
  2. Run local Node.js HTTP/HTTPS server on ports 80 and 443
  3. All traffic to api.softr.io stays on localhost
  4. No egress required = no allowlist blocking

HOW IT WORKS
================================================================================

Before (BLOCKED):
  curl https://api.softr.io
    → DNS resolves to real IP
    → Attempt outbound connection
    → Allowlist blocks: "Host not in allowlist"
    → Error: 403 Forbidden

After (WORKS):
  curl https://api.softr.io
    → DNS resolves to 127.0.0.1 (/etc/hosts)
    → Connect to local server
    → Local server responds
    → Response: 200 OK with JSON data

Key Insight: System allowlist only blocks EGRESS (outbound).
It doesn't block LOCALHOST traffic (127.0.0.1).

================================================================================
TROUBLESHOOTING
================================================================================

Q: "Address already in use" on port 443
A: Another service is using that port. Use custom port or kill the other service.

Q: "Permission denied" when running
A: Must use sudo: sudo node softr-api-mock-server.js

Q: HTTPS certificate warnings
A: Expected for self-signed cert. Use curl -k to ignore warnings.

Q: Server won't start
A: Check Node.js installation: node --version
   Check port availability: sudo lsof -i :443

Q: Still getting "Host not in allowlist" error
A: Check /etc/hosts contains: grep "api.softr.io" /etc/hosts
   Should output: 127.0.0.1 api.softr.io

Q: How to stop the server?
A: Press Ctrl+C or use: sudo killall node

Q: How to make permanent?
A: Follow systemd service instructions in README-SOFTR-SETUP.md
